# オフライン利用（PWA）と動作確認手順

授業観察メモは PWA（Progressive Web App）として動きます。
**一度オンラインで開けば、以降は電波がなくても起動・記録・PDF 表示ができます。**

## 仕組みの概要

| 項目 | 内容 |
| --- | --- |
| Service Worker | `vite-plugin-pwa`（Workbox `generateSW`）。初回表示時にアプリ一式をプリキャッシュする |
| プリキャッシュ対象 | HTML / JS / CSS / アイコン、PDF.js の worker、CMap（日本語 PDF 用）、標準フォント、wasm、ICC |
| PDF.js | worker・CMap 等は CDN ではなく同じサイト（`/lesson_observer/pdfjs/`）から配信（`src/utils/pdfjsSetup.ts`） |
| 記録データ | これまで通り端末内（IndexedDB / 選択したフォルダ）に保存。サーバーには送らない |
| ご意見の送信 | オフライン時は「📥 送信を予約」になり端末に一時保存 → オンライン復帰時（またはアプリ起動時）に自動送信（`src/utils/feedbackOutbox.ts`） |
| 更新 | 新しい版が配信されると画面下に「🔄 新しい版があります」を表示。「今すぐ更新」で記録を保存 → 新しい版に切り替え → 再読み込み。古い版のキャッシュは自動削除 |
| 更新の確認タイミング | 起動時・ホーム画面から復帰したとき・オンラインに戻ったとき・開きっぱなしなら 1 時間ごと |

> ⚠️ **iPad の注意**: Safari で開いたときのデータと、「ホーム画面に追加」したアプリのデータは**別々に保存されます**（共有されません）。
> 授業で使う方を決めて、そちらで記録してください。Safari 側の記録はエクスポート → ホーム画面アプリでインポートで移せます。

## iPad で「ホーム画面に追加」する

1. Safari で `https://tky-och.github.io/lesson_observer/` を開く（**オンラインで**）
2. 画面下に「✅ オフラインで使える準備ができました」と出るまで数秒待つ
3. 共有ボタン（□↑）→「ホーム画面に追加」→「追加」
4. ホーム画面の「授業観察メモ」アイコンから起動する（全画面で開けば OK）
5. 起動後、もう一度「✅ オフラインで使える準備ができました」が出るまで待つ
   （ホーム画面アプリは Safari とキャッシュも別なので、アプリ側でも一度オンラインで開く必要があります）

## オフライン動作の確認手順（iPad・機内モード）

事前準備（オンラインで）:

- 上の「ホーム画面に追加」を済ませ、アプリを一度オンラインで起動しておく
- 確認用 PDF を iPad の「ファイル」に入れておく
  - 実際の授業資料・個人情報を含むファイルは使わないこと
  - 日本語の確認用 PDF は PC で `node scripts/make-offline-test-pdf.mjs` を実行すると `offline-test.pdf` ができる
    （フォントを埋め込まない日本語 PDF なので、文字が出れば CMap もキャッシュされている証拠）

確認（□ にチェック）:

1. □ アプリを完全に終了する（App スイッチャーで上にスワイプ）
2. □ コントロールセンターで **機内モードを ON**（Wi-Fi も OFF になっていることを確認）
3. □ ホーム画面のアイコンから起動 → 画面が表示され、上部に「📴 オフラインで動作中」が出る
4. □ 「📂 セッション」→「＋ 新規セッション」→ タイトルに `テスト` など架空の名前を入れて作成
5. □ 観察メモに文字を入力し、タイムスタンプボタン・手書きタブでの書き込みもできる
6. □ 「💾 保存」→「✅ 保存しました」になる
7. □ 「＋ 資料追加」で確認用 PDF を選ぶ → ページが表示され、日本語の文字が読める
8. □ アプリを完全に終了 → 再び起動（機内モードのまま）→ 4〜7 の記録と PDF タブが残っている
9. □ 「💡 ご意見」→ 送信ボタンが「📥 送信を予約」になっている。テスト文を入れて押す →「オンラインになったら送信します」
10. □ 機内モードを OFF → アプリを開いたまま数秒待つ → 上部の「オフラインで動作中」が消える（予約したご意見はこのとき送信される）
11. □ 確認に使ったテストセッションを削除しておく

## 更新の確認手順

1. `main` に変更をマージ → GitHub Actions のデプロイ完了を待つ
2. iPad でホーム画面アプリを起動（またはバックグラウンドから復帰）
3. 画面下に「🔄 新しい版があります」が出る（出ない場合はアプリを一度終了して再起動）
4. 「今すぐ更新」→ 再読み込みされ、新しい版になる。入力中の記録が残っていることを確認
5. 「あとで」を押した場合は、次回起動時に再度表示される

## PC（Chrome）での確認手順（開発者向け）

```bash
npm run build
npx vite preview          # http://localhost:4173/lesson_observer/
```

1. Chrome で上記 URL を開き、DevTools → Application → Service workers で `sw.js` が activated になっていることを確認
2. Application → Cache storage → `workbox-precache-v2-…` に `pdf.worker.min-*.mjs` と `pdfjs/cmaps/*.bcmap` があること
3. Network タブで **Offline** にして再読み込み → アプリが起動すること（各リクエストが `(ServiceWorker)` から返る）
4. 上の iPad 手順 4〜10 と同じことを行う
5. 更新の確認: 何か文言を変えて再度 `npm run build`（preview は起動したまま）→ ページを再読み込み → 「🔄 新しい版があります」→「今すぐ更新」で切り替わり、Cache storage に古い `index-*.js` が残っていないこと

開発サーバー（`npm run dev`）では Service Worker は無効です。オフライン確認は必ず `build` + `preview` で行ってください。
